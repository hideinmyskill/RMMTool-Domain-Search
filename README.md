# RMM Tool Search 🔍

Web-based search tool for identifying domains potentially associated with **Remote Monitoring and Management (RMM)** tools.

## 🛡 Purpose

This project helps cybersecurity analysts, threat hunters, and SOC teams quickly identify whether a given domain might be linked to known RMM tools, which are commonly used in both legitimate IT operations and malicious remote access campaigns.

## 🔍 Features

- **Search by URL or domain** to identify matching RMM tools.
- **Displays tool name, description, and known associated domains**.

## 👨‍💻 Example Use Case

A phishing investigation reveals a suspicious domain like **tele-desk.com**. Running it through this tool identifies the domain as part of the TeleDesktop RMM tool — often abused in remote scam operations.

## 📢 Contributing

To contribute additional RMM tools or domains, update the **tools.json** file and submit a pull request.
